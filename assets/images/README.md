# Payment Method Images

This directory should contain payment method images used on the checkout page when Direct Payment is enabled.

## Required Images

Add the following PNG images to this directory:

1. **hesabe-new.png** - Main Hesabe logo (used as gateway icon)
2. **knet.png** - KNET payment method logo
3. **mastervisa.png** - Visa/Mastercard payment method logo
4. **amex_new.png** - AMEX payment method logo
5. **apple.png** - Apple Pay payment method logo

## Image Specifications

- **Format**: PNG with transparency
- **Recommended Size**: 50-100px width
- **Aspect Ratio**: Maintain original aspect ratio
- **Background**: Transparent or white

## Where to Get Images

You can obtain official payment method logos from:
- Hesabe branding resources
- Payment network official websites
- Your Hesabe merchant account

## Note

If images are missing, the plugin will still function, but payment method selection may not display icons properly. The plugin will gracefully handle missing images.
